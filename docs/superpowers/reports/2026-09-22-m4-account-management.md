# AI Usage Widget M4 账号管理进展

执行日期：2026-09-22。

## 已完成

- 新增「账号管理…」面板，列出显示名、供应商、来源和脱敏身份。
- 支持设置 aliases、隐藏/显示账号、上移/下移排序。
- 删除操作只移除本工具创建的 `.snapshot`，不会删除外部客户端当前登录。
- 偏好统一持久化到 `ai-config.json`：
  - `accountAliases`
  - `hiddenAccounts`
  - `accountOrder`
- `Apply-WidgetAccountPreferences` 集中处理别名、隐藏和顺序，卡片构建不再由各供应商各自实现。
- 原有 `grok-aliases.json` 继续作为 Grok 显示别名兼容来源，集中配置优先。
- 窗口收到 DPI 变化事件时清除缩放和字体缓存，并重建账号行。
- 单月报表导出前可选择月份和账号；账号列表来自历史稳定行 ID。
- 多账号超过屏幕工作区时窗体高度封顶并启用滚动，不再把底部内容推到屏幕外。

## 发布边界

1. `0.15.0` 对应已有本地历史提交 `fb15bf8`，但本地尚缺 `v0.15.0` tag，远端 Release 状态未核实。
2. 当前未提交的多账号、Cline 和 Grok 容错改动不属于已发布 0.15.0，建议作为 0.16.0 的候选范围。
3. 0.16.0 在完成 M1 的凭证写回并发保护前不得打 tag 或发布。当前入口版本继续保留为 0.15.0，
   直到发布候选明确后再统一提升。
4. 现有 `CHANGELOG.md` 的 `Unreleased` 已承载该候选范围；发布前必须补充 M1 修复并重新打包。
5. 当前基线未调用真实供应商接口，也未完成 UI 目视、长期运行、远端 CI 和 Release 验收。

## M0 结论

M0 的本地代码、测试、打包、安装升级和文档基线已经建立。下一阶段进入 M1，优先处理当前登录切换
与离线账号快照刷新之间的凭证写回竞争，之后再收口 0.16.0 发布范围。

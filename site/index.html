中文

卡片贴着桌面边缘常驻，每行一个供应商，显示已用百分比、窗口重置时间与趋势；悬停即可看到明细， 双击打开对应的官方用量页。数据全部来自你本机已有的登录凭证，不经过任何中转服务器。

English

A small always-on-top card that docks to the edge of your desktop. One row per provider shows the used percentage, the window reset time and a trend line; hover for details and double-click to open the provider's own usage page. Everything is read from credentials already on your machine - nothing is proxied through a third-party server.

安装 / Install

仓库自带安装器，重复执行即为升级，不需要管理员权限：

git clone https://github.com/Regine88/ai-usage-widget
cd ai-usage-widget
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1

常用参数：.\install.ps1 -Status 查看状态，.\install.ps1 -Uninstall 卸载， .\install.ps1 -Uninstall -Purge 连数据一起清掉。

也可以直接下载 Release 里的 zip 安装，或让 Scoop 管理：

.\install.ps1 -Zip .\ai-usage-widget-{{VERSION}}.zip
scoop install https://github.com/Regine88/ai-usage-widget/releases/latest/download/ai-usage-widget.json

不想安装时，双击仓库里的 Start-AiUsageWidget.vbs 就能免安装运行； 想先看界面效果，用 -Demo 参数启动即可看到固定演示数据。

配置 / Configuration

所有开关都在 ai-config.json，也可以在卡片右键「设置…」里改：刷新间隔、供应商开关、透明度、 阈值、静音时段、界面语言、窗口列数、每日汇总与分供应商阈值。配置文件与历史记录只写在本机， 发布包里不会包含任何个人数据。

{
  "intervalSeconds": 300,
  "columns": 2,
  "dailySummary": true,
  "providers": { "grok": true, "copilot": true }
}
